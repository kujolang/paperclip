# Searchable task list

## Objective
Deliver a local task list whose search input filters visible tasks. Keep the fixture offline and free of credentials.

## Delegation
The lead validates this pack. Implementation supplies the application and runs a contained Workcell check. Testing uses Lens to visit the app, type a query, assert hidden and visible results, and capture a screenshot. Review runs an Eval suite. Paperclip owns agent hierarchy and parent-child issues.

## Acceptance
Every required native check must pass for the current source snapshot. A supplied claim or an agent marking an issue done is insufficient. Keep the intentional browser failure beside the corrected attempt.

## Evidence and handoff
Retain the request, human approval, native output, artifacts, run identity and outcome. Report missing evidence and failed cleanup explicitly. No automatic retries, issue assignments, network credentials or publication follow from this document.
